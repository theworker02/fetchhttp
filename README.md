# fetchhttp

Fetch URLs and http query parts with stable normalization.

**Site:** https://theworker02.github.io/fetchhttp/

## Install / run

```bash
git clone https://github.com/theworker02/fetchhttp.git
cd fetchhttp
node src/cli.js
node --test
```
